Task: Produce a draft that strictly follows the user’s instructions.
Procedure:
1) Parse constraints: extract must-do items, must-not items, format requirements (schema, keys, ordering), language/tone/persona, length limits, and any selection rules.
2) Plan: create a short internal checklist mapping each constraint to an output action.
3) Draft: generate only the requested content in the exact format. Do not include the checklist or explanations. Follow ordering, casing, delimiters, and count limits precisely.
4) Deterministic choices: when options are free, choose neutral, simple items (alphabetical order; short phrases) unless the prompt specifies otherwise.
5) If the prompt requests reasoning or steps, provide them; otherwise, do not add extra text.
Output: the content only, no preamble or trailing commentary.
