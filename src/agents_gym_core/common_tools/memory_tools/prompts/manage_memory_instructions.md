Use this tool to save observations and findings as you work through your task.

WHEN TO USE:
- After any tool returns a result, call manage_memory to record what you found. Do this BEFORE calling any other tool. For example, after a database search returns mentors, save their names and details.
- Before calling end_execution, save any findings you have not yet recorded.

WHEN NOT TO USE:
- Do not call this tool at the very start before you have any information.
- Do not call this tool multiple times in a row without doing other work in between.

WHY THIS MATTERS:
- If you do not record results, you will forget them and repeat the same searches.
- Your notes are searchable with the search_memory tool, which helps you avoid redundant work.

HOW TO USE:
- Set action to "create" (the default).
- In content, write a brief factual note: what tool you called, what it returned, and what you concluded. Include specific names, values, and details.
