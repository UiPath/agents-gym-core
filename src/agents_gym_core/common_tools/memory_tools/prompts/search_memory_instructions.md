Use this tool to retrieve results you previously saved with manage_memory. It returns your own notes containing specific names, values, and conclusions.

WHEN TO USE:
- You have already called another tool (like a database search) at least once and received results. Before calling that same tool again, call search_memory instead — your saved notes likely already contain what you need.
- You are about to call end_execution and want to compile your findings.

WHEN NOT TO USE:
- Do not search at the very start of the task when you have not saved anything yet.
- Do not search repeatedly with the same query.

WHY THIS MATTERS:
- Calling the same tool repeatedly with similar queries wastes your limited turns and will not give you new information.
- Your saved notes from manage_memory contain the exact results you need to formulate your final answer and call end_execution.

HOW TO USE:
- Provide a short, specific query describing what you need (e.g. "mentor names for leadership", "timezone GMT+2 results").
